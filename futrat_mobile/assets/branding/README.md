# Futrat app icon

Выбранный вариант: 01, мятная карточка с F на графитовом фоне.

- Фон: `#10201C`.
- Карточка: `#8EE8C1`.
- Буква F — прозрачный вырез в карточке, через который виден фон.
- `futrat-icon.svg` — исходник обычной иконки; `../icon.png` — его PNG 1024×1024. Фон непрозрачен, скругление задаётся системой.
- `futrat-adaptive-foreground.svg` — прозрачный слой Android; `../icon_foreground.png` — PNG 1024×1024. Уменьшение до 64% сохраняет знак внутри центральной безопасной области круглых и других масок.

После изменения SVG отрисуйте PNG с сохранением размеров холста и прозрачности адаптивного слоя, затем из `futrat_mobile` запустите:

```powershell
dart run flutter_launcher_icons
flutter build apk --debug --no-pub
```

Генератор обновляет Android и iOS из настроек `pubspec.yaml`. У iOS удаляется альфа-канал. Старый исходник сохранён локально в `.tools/backups/icon-before-mint-card/` в корне проекта.
