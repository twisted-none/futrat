# ⚽ Futrat — Футбольное приложение-агрегатор

**Futrat** — это кроссплатформенное мобильное приложение для отслеживания футбольной статистики, расписания матчей и участия в турнирах прогнозистов. Приложение предоставляет данные по топовым европейским лигам (АПЛ, Ла Лига, Серия А и др.) в сезоне 2025/2026.

## 🛠 Технологический Стек

Проект реализован в архитектуре **Клиент-Сервер**.

### 🎨 Frontend (Мобильное приложение)
*   **Фреймворк:** [Flutter](https://flutter.dev/) (Dart) — обеспечивает высокую производительность и кроссплатформенность.
*   **State Management:** `Provider` — управление состоянием приложения (авторизация, загрузка данных).
*   **Networking:** `Dio` — мощный HTTP-клиент для запросов к API с поддержкой интерцепторов (авто-подстановка JWT токена).
*   **Navigation:** `GoRouter` — декларативная навигация, управление диплинками и редиректами (защита роутов).
*   **Storage:** `FlutterSecureStorage` — безопасное хранение токенов доступа (JWT) в Keystore/Keychain.
*   **Design:** Кастомная темная тема (`AppTheme`) с использованием градиентов и неоновых акцентов.

### ⚙️ Backend (Серверная часть)
*   **Фреймворк:** [FastAPI](https://fastapi.tiangolo.com/) (Python) — современный асинхронный веб-фреймворк.
*   **Database:** PostgreSQL 15.
*   **ORM:** SQLAlchemy — для взаимодействия с базой данных через объекты Python.
*   **Validation:** Pydantic — строгая типизация и валидация входящих данных.
*   **Security:** 
    *   JWT (JSON Web Tokens) — для аутентификации.
    *   Passlib (Bcrypt) — для хеширования паролей.
*   **External API:** Интеграция с [Football-Data.org](https://www.football-data.org/) для получения реальных данных о матчах и командах.

### 🐳 DevOps & Infrastructure
*   **Docker & Docker Compose:** Полная контейнеризация бекенда и базы данных. Развертывание одной командой.

## 🚀 Основной Функционал

1.  **Авторизация и Персонализация:**
    *   Регистрация и вход (Email/Никнейм + Пароль).
    *   Валидация данных на сервере.
    *   Сохранение сессии пользователя.

2.  **Просмотр Матчей и Турниров:**
    *   Поддержка 6+ топ-лиг (Premier League, La Liga, Bundesliga, Serie A, Ligue 1, RPL).
    *   Автоматическая загрузка расписания и логотипов команд через внешний API.
    *   Фильтрация матчей по Турам (Matchday).
    *   Детальный просмотр матча: статус, счет, минуты голов, авторы голов.

3.  **Система "Избранное":**
    *   Добавление **Команд** в избранное (звезда в карточке матча).
    *   Добавление **Лиг** в избранное (звезда в меню).
    *   Отдельный экран для управления подписками.

4.  **Таблица Лидеров (Leaderboard):**
    *   Рейтинг пользователей (заглушка для демонстрации UI).

## 📥 Установка и Запуск

### Предварительные требования
*   Docker Desktop
*   Flutter SDK

### 1. Запуск Сервера (Backend)

```bash
cd futrat_backend

# 1. Добавьте ваш API Key в app/initial_data.py
# 2. Соберите и запустите контейнеры
docker-compose up --build
```
*Сервер запустится на порту `8000`. База данных автоматически наполнится реальными данными из API при первом старте.*

### 2. Запуск Приложения (Frontend)

1.  Узнайте локальный IP вашего компьютера (например, `192.168.1.56`).
2.  Обновите файл `lib/core/api_client.dart` (или `constants.dart`), указав этот IP.

```bash
cd futrat_mobile
flutter pub get
flutter run
```
