# Active season 2026/27

Приложение закреплено за сезоном 2026/27 (`ACTIVE_SEASON=2026`). `current_matches` — общий фильтр для публичных списков и таблиц, а также профилей с `season=2026`.

- Клубные соревнования: 1 июля 2026 включительно — 1 июля 2027 исключительно, дополнительно в пределах календаря источника.
- МЛС: календарный 2026, также в пределах календаря источника.
- Сборные: актуальный опубликованный розыгрыш в пределах календаря источника; июльское ограничение не применяется.
- PendingDraw/PendingSchedule не возвращают матчи.
- Прошлые матчи не удаляются; прямой доступ по ID, старые прогнозы и оценки сохраняются. Явный исторический параметр профиля оставлен для совместимости; приложение его не предлагает.

Профили по умолчанию используют 2026; список предлагаемых сезонов содержит только 2026. История игрока, продолжение списка и статистика покрытия используют тот же фильтр, что и профиль команды. Обновление сезона в следующем году требует согласованно изменить `ACTIVE_SEASON` в бекенде и `activeSeason`/подпись в мобильном приложении.

Проверки: `tests/test_active_season.py` проверяет старые клубные матчи, границы сезона, МЛС, актуальный и архивный розыгрыши сборных, сохранение записей, профили и отклонение курсора из старого сезона. Полный Docker/PostgreSQL набор: 79 тестов прошли.
