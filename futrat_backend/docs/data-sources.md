# Источники футбольных данных

ESPN обслуживает основные лиги и международные турниры; GOAL API — Кубок России, Кубок Англии и Суперкубок Испании. Локальные ID турниров и существующих матчей сохраняются. Таблицы `provider_matches` и `provider_teams` связывают ID GOAL с локальными записями. ID GOAL не передаются в ESPN summary. Повторный импорт обновляет запись; перенос даты не создаёт новый матч. Составы обновляются без удаления строк, на которые ссылаются оценки.

Сопоставление команды использует ID источника, однозначное нормализованное имя и явные алиасы. При неоднозначности импорт турнира откатывается; требуется уточнение алиаса. Новому ID матча GOAL соответствует существующая запись того же турнира, с теми же командами и днём начала, если она единственная. Нечёткое сравнение названий не применяется.

## Настройка GOAL

Добавьте в `futrat_backend/.env`:

```dotenv
GOAL_API_KEY=replace-with-your-key
GOAL_API_DAILY_LIMIT=900
```

Ключ вводится без `Bearer`. Он используется только бекендом и не передаётся приложению. Не добавляйте рабочий `.env` в Git. В локальном Compose каталог бекенда смонтирован как `/app`, а Pydantic читает `/app/.env`. После изменения настроек:

```powershell
docker compose up -d --no-deps --force-recreate web
```

[Контракт GOAL v1](https://goal-api.com/openapi.json) задаёт Bearer-аутентификацию и адрес `https://api.goal-api.com/v1`. Фактический предел страницы — 100, хотя опубликованная схема указывает 500. Клиент читает страницы до конца и проверяет общее число записей, повторы ID и продвижение offset. Каждый сетевой запрос, в том числе неудачный, учитывается атомарно в `provider_usage`. Лимит по умолчанию — 900 запросов за сутки UTC, допустимый максимум — 1000. Счётчик, HTTP 429 / Retry-After и кеш ответов сохраняются после перезапуска. Другие приложения, использующие тот же ключ, должны учитывать собственные запросы отдельно.

Каталог кубков кешируется на 7 дней. Полный сезон трёх кубков обновляется раз в 6 часов. Объявленные матчи в пределах вчера–завтра проверяются с кешем 10 минут. Детали завершённого матча кешируются на 24 часа, остальных — на 10 минут. Отсутствие ключа, исчерпанный лимит или ошибка источника сохраняют уже загруженные данные. Неудачный ответ не кешируется.

GOAL запрашивается с 1 июля до 30 июня текущего клубного сезона. Матчи вне этих границ и чужого турнира не импортируются. Время берётся из `kickoffUtc`; `matchLive` не используется: этот флаг может оставаться установленным после финального свистка. Без объявленных участников и времени начала матч не показывается как реальная встреча. Поэтому опубликованная заготовка финала может присутствовать в ответе источника, но отсутствовать в приложении.

Лига наций и Кубок африканских наций показывают официальные групповые таблицы ESPN из кеша `official_standings`. Очки и места не вычисляются по матчам плей-офф. Отбор Евро-2028 активируется после появления соответствующего сезона у ESPN; старый ответ за 2024 год отклоняется. Евро-2028 имеет тип `PendingDraw`, не импортирует старые матчи и показывает заглушку. После полной жеребьёвки нужно отдельно включить импорт и сменить этот тип в реестре, предварительно проверив сезон у источника.

Кубки GOAL показывают полный список матчей и недавние результаты. Универсальная сетка клубных еврокубков не подходит для двух путей Кубка России и квалификационных раундов Кубка Англии. Наличие турнира в каталоге не гарантирует публикацию всего будущего календаря или составов каждого матча. Пустой состав у низших дивизионов может быть ограничением источника.

## Проверка и откат

Проверьте `/api/tournaments`, `/api/matches`, `/api/tournaments/{id}/standings` и `/api/matches/{id}`. Повторная загрузка должна сохранять локальные ID и число матчей. Тесты `tests/test_goal_api.py` проверяют квоту, пагинацию, кеш, переносы, сохранение оценок и прогнозов, маршрутизацию источников и заглушки. Рабочий ключ в тестах не используется.

Схема расширяется только новыми таблицами; пользовательские и матчевые таблицы не пересоздаются. Перед загрузкой сохранена локальная копия `.tools/backups/futrat-before-goal.dump`. Для отключения GOAL уберите ключ и перезапустите бекенд: загруженные данные сохранятся. Полное восстановление дампа удалит данные, появившиеся после резервной копии, и требует отдельного решения.
