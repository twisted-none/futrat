# Прогнозы, избранное и профили

Реализация от 17 октября 2026 года. Приложение доступно без регистрации; вход требуется для прогноза, избранного и пользовательской оценки.

## Правила прогнозов

- П1, Х или П2: результат за 90 минут с компенсированным временем. Дополнительное время и серия пенальти не учитываются.
- Верный исход приносит 10 баллов, неверный — 0.
- Лимит: 10 разных матчей с началом в одни календарные сутки по Москве. Дата отправки прогноза не влияет на лимит.
- До начала матча выбор можно менять без дополнительного слота или отменить с освобождением слота. Время проверяется повторно после ожидания блокировки БД.
- Перенос на другую московскую дату освобождает старый слот и требует повторного подтверждения. Отменённый матч аннулируется.
- Если известен только итог после дополнительного времени, прогноз ожидает данных за 90 минут. Восстановление по событиям допускается только при полном согласовании всех голов с итоговым счётом.
- Повторная синхронизация не начисляет баллы повторно; исправления источника отражаются в журнале изменений баллов.

Месячный рейтинг относится к месяцу начала матча по МСК: задержка получения результата не переносит баллы в другой месяц. Есть общий рейтинг, точность, число завершённых прогнозов и собственное место вне первой страницы. При равных баллах выше точность; при равенстве обоих показателей место общее.

Старые записи прогнозов сохранены. Автоматически начислять им баллы задним числом нельзя: у прежней модели отсутствует время создания, необходимое для проверки выбора до начала игры. Старый endpoint создания теперь использует те же ограничения, что и новый.

## Избранное и история

Избранные турниры располагаются перед остальными с сохранением исходного порядка внутри групп. Из избранного можно перейти в турнир, команду или профиль игрока.

Команда открывается у последней завершённой игры. Выше находится сыгранная история, ниже — будущие встречи всех доступных турниров выбранного сезона. Обе стороны подгружаются страницами. Для MLS используется календарный сезон; для остальных поддержанных клубных турниров — июль–июнь.

Игрок связывается с устойчивым ID источника. Старые ID, пользовательские оценки и избранное сохраняются через таблицу соответствий. История включает подтверждённые участия за клуб и сборную, доступные в загруженных турнирах. Запасной без выхода на поле не считается сыгравшим. Возможные будущие встречи показаны отдельно и не обещают участие игрока.

Профиль показывает фото, минуты, голы, передачи, оценку источника и среднюю оценку пользователей. Неизвестное значение отображается прочерком. Сведения об охвате истории позволяют отличить пустую историю от ещё не завершённой загрузки.

## Составы и источники

Внутри матча доступны список и поле, выбор команды, оценки Futrat и оценки источника. Для поля нужны настоящая схема и 11 однозначных стартовых позиций; при отсутствии данных используется список. На узком экране или при крупном шрифте также используется список. Пользовательскую оценку можно поставить после завершения матча только участнику игры; прежний голос редактируется.

ESPN и GOAL остаются основными источниками. Фото берутся из их ответов; TheSportsDB используется как бесплатный запасной источник только при подтверждении личности по команде либо дате рождения. Совпадения имени недостаточно. У оценок указан источник; сезонная оценка не подставляется вместо оценки матча. В проверенных ответах GOAL индивидуальные оценки отсутствовали, поэтому полного покрытия внешними оценками сейчас нет. SofaScore и WhoScored не подключены.

Загрузка истории выполняется фоном: до 8 матчей и до 8 запросов фотографий за минутный цикл, с сохранением состояния, повторными попытками и блокировкой от параллельных исполнителей. Просмотр профиля ставит работу в очередь, не ожидая внешние API внутри HTTP-запроса. История ограничена турнирами и данными источников; полный архив карьеры не гарантируется.

## API

| Маршрут | Назначение |
| --- | --- |
| `PUT /interactive/predictions/{match_id}` | Выбрать исход `HOME`, `DRAW`, `AWAY` |
| `DELETE /interactive/predictions/{match_id}` | Отменить свой прогноз до начала |
| `GET /interactive/predictions` | Свои прогнозы с пагинацией и фильтром даты |
| `GET /interactive/prediction-quota?day=YYYY-MM-DD` | Занятые и свободные слоты московской даты |
| `GET /interactive/rankings?month=YYYY-MM` | Публичный месячный рейтинг; без месяца — общий |
| `GET /interactive/my-rank?month=YYYY-MM` | Собственное место |
| `GET /api/teams/{id}/matches` | Сезонная лента команды, курсоры истории и расписания |
| `GET /api/players/{id}` | Канонический профиль игрока |
| `GET /api/players/{id}/matches` | Подтверждённые участия, охват загрузки и возможное расписание |

## Основные файлы

- `app/feature_models.py`: дополнительные таблицы квот, прогнозов, журнала баллов, результатов за 90 минут, соответствий игроков и деталей составов.
- `app/forecasts.py`, `app/routers/forecasts.py`: правила, расчёт, рейтинги и HTTP-контракт.
- `app/lineups.py`, `app/player_history.py`, `app/routers/profiles.py`: идентичность игроков, статистика, очередь и профили.
- `app/match_sync.py`, `app/goal_sync.py`, `app/routers/data.py`: получение результатов и составов из источников.
- `../futrat_mobile/lib/screens/forecasts_screen.dart`, `team_screen.dart`, `player_screen.dart`: новые экраны.
- `../futrat_mobile/lib/widgets/lineup_view.dart`, `match_tile.dart`: составы и карточки матчей.
- `../futrat_mobile/lib/screens/favorites_screen.dart`, `../futrat_mobile/lib/providers/data_provider.dart`: переходы и приоритет избранного.
- `tests/test_forecasts.py`, `tests/test_profiles.py`, `../futrat_mobile/test/forecasts_test.dart`, `../futrat_mobile/test/profiles_test.dart`: проверки поведения.

## Проверка и эксплуатация

Проверены границы суток МСК, изменение и отмена выбора, перенос, поздняя обработка результата, дополнительное время, коррекция начислений, старый endpoint и ожидание блокировок. Отдельная PostgreSQL проверяет 11 конкурентных запросов: принимаются ровно 10. Мутация ограничения квоты обнаруживается тестом.

Итоговые проверки: 76 тестов и один пропуск конкурентного PostgreSQL-теста на Windows/SQLite; 77 тестов на Linux/PostgreSQL; 11 Flutter-тестов. Android debug APK собирается без установки на телефон. Статический анализ Flutter не обнаруживает ошибок; предупреждения проекта перечисляются самим анализатором.

Перед изменениями создан локальный резервный дамп `.tools/backups/futrat-before-interactive.dump`. Добавлены таблицы; существующие данные не удаляются. Для отката к прежнему приложению можно вернуть прежний код и оставить дополнительные таблицы. Восстановление дампа удалит более новые данные и требует отдельного решения.

APK: `../futrat_mobile/build/app/outputs/flutter-apk/app-debug.apk`. Текущая конфигурация приложения обращается к `127.0.0.1:8000`; при будущем запуске на телефоне потребуется USB-проброс ADB либо настройка доступного адреса бекенда. Установка на телефон по просьбе пользователя не выполнялась.

Достижения, серии удачных прогнозов, мини-лиги друзей и уведомления о старте избранных матчей остаются следующими возможными расширениями.
