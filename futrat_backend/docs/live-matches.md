# Live match classification

## Incident

18 октября 2026 в «Матчах сейчас» отображался матч Чертаново — Чита (local ID 5722). GOAL fixture `cmsfbnv2j7t3fuj07m9jz4qxc` в сохранённом ответе источника имел `matchStatus=LIVE`, `kickoffUtc=2026-08-12T15:00:00Z`, счёт 3:0. Импорт корректно переводил LIVE в IN_PLAY, но приложение считало live почти любой статус вне четырёх исключений, без даты.

## Rule

Матч считается live только при одновременном выполнении двух условий:

- Статус IN_PLAY, LIVE, HALF_TIME, HALFTIME, HT, EXTRA_TIME, ET, PENALTIES, PENALTY_SHOOTOUT либо распознанные футбольные минуты ESPN (`45'`, `90+3'`, `90'+3'`).
- Начало уже наступило и прошло не более шести часов, включая границу. Сравниваются абсолютные моменты времени, поэтому переход через полночь и часовые пояса не обрывают матч.

POSTPONED, DELAYED, CANCELLED, ABANDONED, SUSPENDED, FINISHED, SCHEDULED и неизвестные статусы live не являются. Ограничение в шесть часов — правило отображения с запасом для задержек, дополнительного времени и пенальти; оно не доказывает завершение.

## API and app

`MatchResponse.is_live` — вычисляемый bool, без изменения БД. `GET /api/matches?live=true` возвращает только live-матчи; без параметра список сезона сохраняется. Исходные status, дата, счёт и идентификаторы не меняются, результаты прогнозов из давности не выводятся. Клиент получает is_live во всех MatchResponse, повторно проверяет время и статусы локально, а при старом API без поля использует ту же локальную проверку. Серверный false не переопределяется локально.

В приложении общий предикат используется фильтром «Сейчас», метками в группах и турах, шапкой матча и его таймером. Старый live-статус в истории отображается как «Уточняется» / «СТАТУС УТОЧНЯЕТСЯ»; история и карточка остаются доступны. Источник должен подтвердить завершение для выставления FINISHED и расчёта результата.

Регрессии: `tests/test_live_matches.py`, `futrat_mobile/test/live_matches_test.dart`. Проверяются августовский случай, актуальная игра, неизвестные и прерванные статусы, будущее начало, полночь, шестичасовая граница, локальная фильтрация и отображение истории без LIVE.
