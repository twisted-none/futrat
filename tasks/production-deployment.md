# Production deployment preparation

## Approved brief

Подготовить Futrat к запуску на Ubuntu, IP `176.108.255.248`, с существующими Docker-контейнерами Caddy и PostgreSQL 15 (`postgresql`). Создать отдельную роль/БД Futrat, сохранить остальные проекты, подготовить HTTPS, эксплуатационные инструкции и локальные проверки. Фактическое развёртывание и установка APK следуют после доступности серверного API.

## Implementation

- `futrat_backend/compose.prod.yml`: только API, внешние сети Caddy/PostgreSQL, без host ports и исходников в bind mount, один worker, restart/healthcheck, ограниченные логи.
- Docker target `production`: UID/GID 10001, production по умолчанию; прежний target `runtime` остаётся последним для разработки.
- Production settings: отдельные PostgreSQL database/role `futrat`, HS256, положительный срок токена, непустые нешаблонные секреты; настройки не выводят входные значения при ошибках.
- Production не создаёт тестового Admin и блокирует запуск при его сохранённом тестовом пароле; пользователей при старте не удаляет.
- Пул PostgreSQL ограничен десятью соединениями, проверка `/health/ready` использует БД и отвечает 503 без внутренних деталей при сбое.
- `deploy/`: шаблон конфигурации, SQL первого создания роли/БД, дополнение Caddy, backup.sh и инструкция сети/TLS/данные/обновление/откат/Android.
- Секреты из локальных `.env` не читались и не копировались. В шаблоне только заглушки.
