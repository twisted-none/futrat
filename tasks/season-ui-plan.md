# Season and match interface

Approved: 18 October 2026, пользователь подтвердил уточнённый brief.

## Scope

Только сезон 2026/27 в приложении; МЛС 2026 и актуальные розыгрыши сборных сохранены. Сворачиваемые группы в Today/Live. Карточки матчей открывают матч. Только пользовательские оценки без подписи бренда. Общая обводка эмблемы и названия команды в шапке матча.
