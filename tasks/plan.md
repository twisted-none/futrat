# Predictions, favorites and player profiles

## Approved brief

Подтверждено продолжение реализации 17 октября 2026. До 10 матчей на дату начала по МСК; П1/Х/П2 за 90 минут, +10/0, изменение до начала, отмена освобождает слот. Перенос на другую дату требует повторного подтверждения. Гостевой просмотр сохраняется.

Избранные турниры выше остальных; переходы на лигу, команду, игрока. Лента команды открывается у последней сыгранной встречи: история выше, расписание ниже, все турниры выбранного сезона. Единый профиль футболиста для клуба/сборной, фото, подтверждённые участия, голевые действия, оценки источника. Составы: поле/список, пользовательские/внешние оценки.

## Implementation order

1. Проверить реальные поля источников; написать серверные тесты прогнозов.
2. Реализовать квоту с блокировкой PostgreSQL, расчёт и коррекции, месячные/общие таблицы, Flutter.
3. Избранные турниры, переходы, страница команды с двусторонней лентой.
4. Устойчивые ID игроков, составы, фото, статистика, фоновая догрузка истории.
5. Поле, схемы, переключение оценок. Внешнее значение относится к конкретному матчу.
6. Ревью, Windows/Linux/PostgreSQL и Flutter, APK, документация и граф.

## Constraints

Сохранять существующие изменения, ID, оценки и избранное. Секреты не читать и не выводить. Новые функции по возможности используют дополнительные таблицы. ESPN/GOAL основные, TheSportsDB дополняет фото. Платные сервисы не подключать. Отсутствующие оценки/схемы/статистику не выдумывать; показывать покрытие истории. Фоновые запросы уважают квоту. Достижения, мини-лиги и уведомления остаются необязательными последующими расширениями.

## Verification

Полночь МСК, 11-й выбор, параллельные запросы PostgreSQL, начатый матч, перенос, дополнительное время, повторный расчёт и коррекция. Навигация избранного, единый игрок клуба/сборной, неизвестные данные и расстановка. Сохранять осмысленные регрессионные проверки.
